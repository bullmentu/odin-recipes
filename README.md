Project: Website Development
Introduction

It’s time to put the HTML and web development knowledge you have acquired into practice. In this project, you are going to build a basic website from scratch.

Throughout the project, you will demonstrate your ability to structure web pages using HTML, create links between pages, add images, and organise content effectively. By the time you have completed the project, you will have gained practical experience in writing clean HTML code, understanding website structure, and building a functional website.
